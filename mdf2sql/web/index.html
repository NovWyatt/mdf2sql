        Cách import file .sql này vào SQL Server
        1. Mở SQL Server Management Studio, chọn File > Open > File, chọn file .sql rồi bấm Execute (F5).
        2. Hoặc chạy dòng lệnh:
        Cách import file .sql này vào phpMyAdmin
        1. Mở phpMyAdmin, vào tab Import, chọn file này rồi bấm Go. File đã có sẵn lệnh tạo database nên không cần tạo trước.
        2. File lớn hơn mức upload_max_filesize của PHP thì bật thêm tuỳ chọn nén .gz ở cột bên trái, phpMyAdmin tự giải nén khi nạp.
